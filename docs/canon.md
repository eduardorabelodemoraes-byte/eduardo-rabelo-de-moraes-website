# canon.md

# THE THRESHOLD CANON

## Permanent Decisions of the Project

Version 2.0

---

# Purpose

The Canon records permanent project decisions.

It does not explain them.

It does not justify them.

It records only decisions that have been explicitly approved.

Everything contained here is considered authoritative.

---

# Identity

1. Threshold is an editorial project.

2. Editorial integrity always prevails over visual novelty.

3. Professional judgment is the central subject of the project.

---

# Home

4. The Home is a complete editorial world.

5. The Home represents stability.

6. The Home must remain calm.

7. The Home must remain immediately recognizable.

8. Typography shall never be sacrificed.

9. Editorial hierarchy shall never be sacrificed.

10. Legibility shall never be sacrificed.

---

# Game Localization

11. Game Localization is an independent editorial world.

12. It expands the project without contradicting the Home.

13. It possesses its own perceptual identity.

---

# Crossing

14. Crossing is the architectural center of the project.

15. The visitor crosses worlds rather than changes pages.

16. Crossing is not navigation.

17. Crossing is not animation.

18. Crossing is not a loading sequence.

19. Crossing is not a visual effect.

20. Crossing is a perceptual experience.

21. Recognition of the Home shall remain throughout the Crossing.

22. Editorial integrity shall remain throughout the Crossing.

---

# Duration

23. The complete Crossing lasts approximately five seconds.

24. Duration exists to support perception.

25. Duration shall never become spectacle.

---

# Materiality

26. The apparent material condition of the environment may change.

27. Editorial identity shall not.

28. Recognition shall not.

29. Structure shall not.

30. Legibility shall not.

---

# Technology

31. Phenomenology precedes implementation.

32. Technology follows phenomenology.

33. No implementation technology possesses artistic authority.

34. Any implementation may be replaced.

---

# Laboratory

35. The Threshold Laboratory exists to reduce uncertainty.

36. Every hypothesis must be falsifiable.

37. Every hypothesis must be observable.

38. Every experiment must answer one question.

39. Negative results constitute knowledge.

40. Implementations are temporary.

41. Knowledge is permanent.

---

# Documentation

42. The Manifesto defines identity.

43. The Canon defines permanent decisions.

44. The Handbook defines operational methodology.

45. The Architecture defines conceptual organization.

46. The Glossary defines official terminology.

47. The Laboratory Log preserves experimental history.

48. The Current Mission defines the active objective.

49. The Implementation Task defines the current implementation work.

---

# Authority

50. The Canon overrides prompts.

51. The Canon overrides temporary implementation decisions.

52. Nothing enters the Canon without explicit approval.

53. Experiments never become canonical.

54. Code never becomes canonical.

55. Only approved decisions become Canon.
