# THRESHOLD LABORATORY LOG

## Official Experimental Record

Version 2.0

---

# Purpose

The Laboratory Log is the permanent scientific record of the Threshold Laboratory.

Its function is to preserve the history of investigation exactly as it occurred.

The Log never rewrites history.

The Log never retroactively improves experiments.

Each entry records what was known at that moment.

Knowledge grows chronologically.

History remains intact.

---

# Observer Reports

Observer reports are historical evidence.

They are preserved exactly as expressed.

Meaning may never be altered.

Interpretation never replaces observation.

# Experiment 01-A

Identifier

Experiment Perceptual 01-A

Phase

Phase 1

Question

Can an almost instantaneous change in perceived material condition be consciously experienced while preserving complete editorial recognition?

Objective

Investigate the perceptual viability of an extremely brief Crossing.

Hypothesis

The Home could remain completely recognizable while momentarily appearing to possess another material condition.

Invariants

Editorial composition.

Typography.

Hierarchy.

Recognition.

Legibility.

Variables

SVG displacement implementation.

Approximately 160 ms duration.

Implementation

Static isolated experiment.

Professional website unchanged.

Repository unchanged.

Observer Protocol

No leading explanations.

Observer Report

No validated observer report recorded.

Result

Inconclusive.

Conclusion

The experiment did not provide sufficient observational evidence to support or refute the hypothesis.

Lessons Learned

Implementation technology alone does not determine perceptual success.

Next Question

Would a more controllable implementation clarify the hypothesis?

# Experiment 01-B

Identifier

Experiment Perceptual 01-B

Phase

Phase 1

Question

Can the same perceptual hypothesis be better evaluated using a WebGL implementation?

Objective

Remove implementation uncertainty while preserving the original hypothesis.

Hypothesis

The observer would perceive that the Home no longer appeared completely fixed while remaining immediately recognizable.

Invariants

Editorial composition.

Typography.

Hierarchy.

Recognition.

Legibility.

Variables

Rendering implementation.

Implementation architecture.

Implementation

Static WebGL experiment.

Professional website unchanged.

Repository unchanged.

Observer Protocol

Single spontaneous observer.

No prior explanation.

Observer Report

"Nothing happened."

Video evidence preserved.

Result

Refuted.

Conclusion

The intended perception was not observed.

Lessons Learned

A technically functioning implementation does not necessarily produce the intended perceptual experience.

Implementation success and perceptual success must always be evaluated independently.

Next Question

Should the project continue pursuing an almost instantaneous Crossing?

---

# Phase Decision

Following Experiment 01-B, the project adopted a new direction.

The objective of producing the Crossing within approximately 160 milliseconds was abandoned.

The project now investigates a consciously experienced Crossing lasting approximately five seconds.

This decision does not invalidate previous experiments.

Their historical purpose remains fulfilled.

---

# Current State of Knowledge

The project no longer investigates subliminal perceptual events.

The project now investigates gradual perceptual transformation.

Future experiments belong to this new research direction.
